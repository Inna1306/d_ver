# d_ver — вёрстка интерфейса библиотеки

Статическая вёрстка по макетам репозитория [Inna1306/d_ver](https://github.com/Inna1306/d_ver).

## Фреймворк

Используется **Bootstrap 5.3.3** (CSS и JS bundle) через CDN: сетка `row` / `col-*`, адаптивность и базовые компоненты. Поверх Bootstrap подключён собственный `css/styles.css` с дизайн-токенами и компонентами проекта.

## Структура

```text
.
├── index.html
├── README.md
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
```

## Дизайн-токены

| Токен | Значение |
|---|---|
| Фон | `#F6FFF7` |
| Акцент | `#F0FFF1` |
| Формы | `#D6EAD8` |
| Зелёный | `#6AA378` |
| Жёлтый | `#FFC33E` |
| Карточки | `#FFFEF0` |
| Плейсхолдер | `#93A497` |
| Удаление | `#E5484D` |

## Экраны

- Публичные: вход, поиск, пустой результат, бронирование, активные брони.
- Читатель: профиль, брони, история, избранное, уведомления.
- Менеджер: обзор, книги, брони, читатели, библиотека, CRUD.
- Администратор: обзор, пользователи, библиотеки, книги, брони, CRUD.
- Служебные: assets, 404.

## Запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.
